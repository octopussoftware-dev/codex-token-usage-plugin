How tokens are counted

Total tokens = input + output. Cache reads and writes are included in input; reasoning is included in output. These are processed tokens across requests, so reused context can appear more than once.

Day, Week, and Month cover the last 24 hours, 7 days, and 30 days, using the timestamp of each usage record. Changes compare that window with the immediately preceding window of the same length: (current − previous) ÷ previous × 100. Chats with usage in either window are shown, including chats whose current usage is zero.

The overall total hides its comparison when the previous window has no recorded tokens. Chat and project rows also omit New when the previous total was zero. In the detail view, New means the previous window had zero tokens. No change means the totals are equal. Comparisons are unavailable if either window has incomplete usage. All time has no previous window. Hover over a change for the exact previous and current counts.

Project subtotals, comparisons and ranking include only the chats currently shown and their subagents. Project changes use combined totals, not an average of chat percentages. Load more chats to expand coverage.

Most recent ranks the latest chat activity first. Token usage ranks the largest current totals first. With grouping on, projects rank by their latest chat activity or combined tokens; chats within each project use the same order.

Account allowance comes from your local Codex sign-in and is shared across chats. Its reset windows are independent of these filters. Remaining allowance is 100% minus the reported percentage used; it cannot be converted into a remaining-token count. With Live enabled, allowance refreshes once a minute. Refresh also requests a new reading. Missing limits show as unavailable, older readings are labeled, and a reset is never assumed until a new reading arrives. Hover over the allowance for its reset countdown and exact local time.

Compact totals are rounded for readability. Hover over a total or open an agent’s breakdown for exact counts. A + marks a partial total; — means usage is unavailable.
